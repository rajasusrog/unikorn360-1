# UNIKORN360 Creator Network & Services — Supabase Setup Guide

This guide details how to configure Supabase PostgreSQL, Supabase Storage, and Supabase Auth for the UNIKORN360 Creator Network and Services application.

---

## 1. Environment Variables Configuration

Copy `.env.example` to `.env` (or configure in your production environment settings):

```bash
# ==============================================================================
# SUPABASE CONFIGURATION
# ==============================================================================

# 1. Supabase Project Base URL (Required for both Server and Browser)
SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_URL=https://your-project-id.supabase.co

# 2. Supabase Publishable / Anonymous Key (Safe for browser client & user token verification)
# Preferred modern names:
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
# Supported legacy fallback names:
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
SUPABASE_ANON_KEY=eyJhbGciOi...

# 3. Supabase Server Secret Key (STRICTLY CONFIDENTIAL - SERVER-SIDE ONLY)
# Preferred modern name:
SUPABASE_SECRET_KEY=sb_secret_...
# Supported legacy fallback name:
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...

PORT=3000
```

> **Security Guarantee**: `SUPABASE_SECRET_KEY` (and legacy `SUPABASE_SERVICE_ROLE_KEY`) is loaded exclusively in `server.ts` through Node.js environment variables. It is never included in client bundles, `VITE_` variables, public API responses, or static assets. The server also refuses to substitute a publishable/anon key for privileged operations.

## 2. Database Migration (PostgreSQL & RLS)

Because four baseline migrations share the `20261028_` date prefix (`20261028_services_architecture.sql` creates the `service_divisions` and `service_catalog` tables that `20261028_location_neutral_update.sql` and `20261028_reorganize_services_6_divisions.sql` update), always apply migrations in the following **deterministic dependency order**:

1. `/supabase/migrations/20261028_services_architecture.sql`
2. `/supabase/migrations/20261028_location_neutral_update.sql`
3. `/supabase/migrations/20261028_reorganize_services_6_divisions.sql`
4. `/supabase/migrations/20261028_creator_network_tables.sql`
5. `/supabase/migrations/20261029_fix_admin_auth_and_rls.sql`
6. `/supabase/migrations/20261030_fix_evaluator_rpc_and_activity_leak.sql`
7. `/supabase/migrations/20261031_strict_evaluator_projection_and_notes_privacy.sql`

### How to Apply:
1. Log in to the [Supabase Dashboard](https://supabase.com/dashboard).
2. Open your project and navigate to the **SQL Editor** tab.
3. Run the 7 migrations above in exact sequential order (or for an existing database already at `20261030`, run `20261031_strict_evaluator_projection_and_notes_privacy.sql`).

### Administrator Membership Table (`creator_admin_users`):
- Explicit roles: `superadmin`, `admin`, `evaluator`.
- Authorization is verified exclusively against this protected table via server-side session checks and PostgreSQL RLS functions.
- Self-promotion, editable user metadata, and localStorage flags are strictly rejected.

## 3. Storage Bucket Configuration (`creator-submissions`)

The migration automatically creates the `creator-submissions` bucket. If you need to verify or configure it manually:

1. In Supabase Dashboard, go to **Storage** -> **Buckets**.
2. Verify the bucket named `creator-submissions` exists:
   - **Public bucket**: Disabled (`public = false`).
   - **Allowed MIME types**: `video/mp4`, `video/quicktime`, `image/jpeg`, `image/png`, `application/pdf`.
   - **File size limit**: 30 MB (31,457,280 bytes).
3. Storage Security:
   - Public direct downloads are forbidden.
   - File uploads are authenticated via short-lived signed upload URLs (`createSignedUploadUrl`) generated by `/api/creators/upload-sign`.
   - File reviews in the Admin Console use 15-minute expiring signed download URLs (`createSignedUrl`) generated by `/api/admin/creators/signed-download`.

## 4. Supabase Auth & Administrator Provisioning

The UNIKORN360 Creator Network admin portal uses the Supabase Auth SDK (`@supabase/supabase-js`) for administrative sessions and server-side verification against `creator_admin_users`. All PIN authentication, custom `localStorage` token keys (`unikorn360_admin_token`, `unikorn360_admin_pin`, `unikorn360_admin_session`), and email bypasses have been removed.

### Step 1: Create an Admin User in Supabase Auth
1. Go to **Authentication** -> **Users** in the Supabase Dashboard.
2. Click **Add user** -> **Create user**.
3. Enter the administrator's email and a strong password.
4. Check **Auto Confirm User** and click **Create user**.
5. Copy the generated User ID (UUID).

### Step 2: Grant Administrator Privileges (Trusted Procedure)
Run this query in the Supabase SQL Editor using the generated Auth User UUID:
```sql
INSERT INTO creator_admin_users (authenticated_user_id, email, role)
VALUES ('<PASTE_USER_UUID_HERE>', 'founder@unikorn360.com', 'superadmin')
ON CONFLICT (authenticated_user_id) DO UPDATE SET role = 'superadmin';
```

Role Permissions:
- `superadmin`: Full management, creator deletion, payment recording, admin membership management.
- `admin`: Application management, notes, campaigns, evaluations, service catalogue edits. (No creator deletion, payment management, or membership changes).
- `evaluator`: Read-only creator profiles and portfolio assets for scoring, score submission. `payments`, `ip_hash`, and internal `admin_notes` are excluded in both the Express API projection (`projectCreatorForRole`) and the `public.get_creator_applications_for_evaluator()` PostgreSQL RPC. Evaluator-visible `activity_log` entries are constructed exclusively from an explicit 4-event allowlist (`application_submitted`, `status_updated`, `campaigns_updated`, `evaluation_submitted`) with validated `id` and ISO-8601 `timestamp` and fixed display summaries, never copying free-text `action`, `details`, `actor_email`, or nested metadata.

### Step 3: Log In to the Admin Console
1. Navigate to `/admin/login` on the website.
2. Enter the administrator email and password.
3. The browser authenticates with Supabase Auth (`supabase.auth.signInWithPassword`) so the Supabase SDK manages session persistence and token refresh, then verifies administrator membership and role via `GET /api/admin/auth/me`.

## 5. Creator Network Application Pipeline

- **Application Form**: `/creators/apply`
  - 5-step intuitive registration workflow.
  - Honeypot fields (`company_website_hp`, `business_tax_id_hp`) prevent automated bot submissions.
  - Progressive upload with live upload progress percentage.
  - Real-time client & server validation on social URLs, phone numbers, and portfolio links.
- **Admin Management Console**: `/admin`
  - Filter applications by status (`pending`, `shortlisted`, `contracted`, `rejected`), tier (`nano`, `micro`, `mid_tier`, `macro`), and Tamil Nadu district.
  - 10-Criteria Evaluation Matrix with instant score calculations.
  - Secure signed download previews for private video reels, insight screenshots, and media kits.
  - CSV export for campaign planning.
